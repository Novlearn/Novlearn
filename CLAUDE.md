# Claude Code

**Aucun push direct sur `main` ou `develop`. Aucune pull request vers `main`. Pousser uniquement sa branche de tâche et ouvrir les PR exclusivement vers `develop`.**

Lire [AGENTS.md](AGENTS.md) avant toute modification et appliquer ses règles de contribution : une tâche par branche, une pull request vers `develop`, du code simple réutilisant l'existant, le respect des responsabilités frontend/backend et du système de design. Les interventions sur le VPS, les fichiers YAML, les workflows et le déploiement sont exclues des tâches courantes; elles nécessitent une demande explicite dédiée. Ne pas committer directement sur `develop` ou `main`, ni fusionner une PR sans demande explicite du responsable.

Les consignes de dépôt, l'architecture et les commandes de développement sont dans [AGENTS.md](AGENTS.md). Le guide d'exploitation, de configuration et de restauration est dans [README.md](README.md).
